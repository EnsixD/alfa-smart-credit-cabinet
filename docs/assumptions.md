# Допущения и упрощения

| Область | Как в прототипе | Как в продуктиве |
|---|---|---|
| ЕГРЮЛ/ЕГРИП, ФНС «Прозрачный бизнес», БКИ | Сервис `mock-gateway` с фикстурами по ИНН и детерминированной генерацией для прочих ИНН; контракты упрощены | Интеграции через шину банка, реальные контракты источников |
| Подписание договора | Простая ЭП: 6-значный код показывается в кабинете (не SMS — сценарий целиком внутри продукта) | УКЭП/ПЭП через сервис подписи банка |
| Выдача средств | `POST /payments/disburse` в mock-gateway, баланс компании увеличивается в БД | АБС банка |
| Данные «внутри банка» | Поля компании `account_turnover_month`, `balance` | Хранилище транзакций |
| Распознавание документов | Поиск показателей («Выручка: …») в текстовом слое файла | OCR/IDP-сервис |
| Скоринг | Прозрачная балльная модель из YAML | Статистическая/ML-модель + валидация |
| Миграции БД | `create_all` при старте | Alembic |
| Хранение файлов | В БД (`LargeBinary`) | S3-совместимое хранилище |
| Аутентификация | Логин/пароль + JWT | Корпоративный IdP (Keycloak/OIDC), MFA |
| Новости | 32 синтетических материала с тегами | CMS + рекомендательный сервис |
| LLM | Опционально, Qwen2.5 через Ollama | Корпоративный инференс open-weights моделей |

Все данные о компаниях, людях, документах и финансах — **синтетические**, совпадения случайны.
