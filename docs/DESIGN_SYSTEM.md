# Визуальная система «Вектор»

## Основа

Красный акцент #ef3124, светлый Hero #f8f7f5, графитовые блоки #111114, белые поверхности и крупная типографика. Небольшие скругления кнопок, ясная иерархия и достаточно места для текста. Название бренда остаётся текстом; монограмма хранится в frontend/public/img/vektor-monogram.png.

## Движение

- PortfolioGrid повторяет алгоритм волн квадратов из Ensi - Portfolio v2/src/Background.tsx с красной палитрой. Фон движется автоматически и не зависит от указателя.
- Canvas приостанавливается вне экрана и в скрытой вкладке. prefers-reduced-motion оставляет статичный кадр.
- React Bits: SplitText для заголовков, FadeContent для появления секций, SpotlightCard для сводок.
- Motion управляет переходами фильтров, вкладок, карточек и платёжных представлений. SmoothHeight плавно меняет высоту каталога.
- Основные кнопки Hero неподвижны при наведении: меняются цвет, рамка и подсветка. Магнитное движение отключено.

## Навигация и слои

Публичная навигация расположена по центру: компактные кнопки с единым индикатором Motion. Активное состояние остаётся красным при наведении. Фон Hero плавно смещается при прокрутке; при сокращении движения параллакс отключён. В кабинете она скрыта: разделы доступны через боковое меню. Мобильное публичное меню открывается на весь экран. Поиск вынесен в body через portal, размывает всю страницу и удерживает фокус. Общая блокировка прокрутки компенсирует ширину scrollbar, чтобы страница не смещалась.

## Основные экраны

- Главная: центральный Hero, каталог финансирования, интерактивные этапы, демонстрация кабинета, FAQ и завершающий блок.
- Вход: тёмная анимированная левая часть и форма справа. Демосценарии открываются в dialog с анимацией содержимого и переключения ролей.
- Кабинет: сводки фактических демоданных, заявки и ссылки на договоры.
- Заявка: фиксированная высота доступной области, вкладки, разбивка истории и проверок на страницы; выдача с отдельным анимированным подтверждением.
- Кредит: отдельная страница продукта /credits/:code и договора /cabinet/loans/:id. Диаграмма, таблица, выбор месяца и CSV.

Предварительный расчёт продукта обозначен как оценка. Плановый график договора не обозначает фактически совершённые платежи.

## Реестр компонентов

React Bits подключён через @react-bits в components.json и frontend/components.json. Источники находятся в frontend/src/components/reactbits, лицензия сохранена рядом. Для добавления компонентов используйте реестр из каталога frontend.
