# Сценарий видеодемонстрации

Длительность — 5–7 минут. Запись экрана: OBS Studio или Xbox Game Bar (`Win + Alt + R`), 1080p.
Перед записью: `start.bat`, затем `docker compose exec api python -m app.reset_data`,
чтобы у демоклиентов не было старых заявок.

| # | Время | Что показываем | Что говорим |
|---|---|---|---|
| 1 | 0:00 | Терминал: двойной клик по `start.bat`, сервисы поднимаются, открывается браузер | Решение запускается одной командой в Docker, всё работает локально, без доступа к системам банка |
| 2 | 0:30 | Главная: hero, продукты, «Как это работает», FAQ | Публичная витрина: предприниматель без банковской экспертизы понимает варианты финансирования |
| 3 | 1:00 | Вход → «Открыть демоверсию» → `client_good` | Демоаккаунты для каждого сценария, вход в один клик |
| 4 | 1:15 | Кабинет: главная, **лента новостей**, открыть статью, «Почему вы это видите» | Лента подбирается под отрасль, размер бизнеса и статус заявки |
| 5 | 1:45 | Новая заявка: цель → продукт → сумма и срок → данные компании подставлены → согласия → отправка | Мастер из 4 шагов, данные компании не вводятся повторно, всё сохраняется как черновик |
| 6 | 2:30 | Экран заявки: статусы меняются вживую — проверка, ЕГРЮЛ/ФНС/БКИ, скоринг, **Одобрено** | Фоновый конвейер: проверка полноты, обогащение из внешних источников (моки), скоринг, кредитная политика |
| 7 | 3:15 | Принять условия → код подписи → **Деньги зачислены** → страница кредита, график, экспорт CSV | Подписание и выдача смоделированы внутри продукта, без SMS |
| 8 | 3:45 | Выйти → `client_counter`, заявка 5 млн на 12 мес. → **встречное предложение** | Решение не бинарное: банк предлагает другие условия |
| 9 | 4:15 | `client_manual` → крупная заявка → `underwriter`: очередь, разбор скоринга, «Эскалировать» → `approver`: «Одобрить» | Ручное рассмотрение, роли и полномочия, аудит действий |
| 10 | 5:15 | `client_young` → другая лента; `admin` → БКИ «Недоступен» → заявка уходит к специалисту | Персонализация и отказоустойчивость: сбой интеграции не ломает процесс |
| 11 | 5:45 | `localhost:8000/docs`, папка `docs/` | OpenAPI, Postman, диаграмма состояний, модель данных, тесты |
| 12 | 6:15 | Итоговый слайд | Что вошло в MVP, ограничения, планы развития |
