# Сценарий видеодемонстрации

Видео необязательно, но страхует от проблем с запуском у экспертов. Организаторы просят показать
**ключевой сценарий: составление и обработку кредитной заявки в личном кабинете**. Презентация не нужна.

Длительность — 4–6 минут, 1080p. Запись: OBS Studio или Xbox Game Bar (`Win + Alt + R`).
Перед записью: `start.bat`, затем `docker compose exec api python -m app.reset_data`,
чтобы у демоклиентов не было старых заявок. Голос за кадром или субтитры — по желанию.

| # | Время | Что показываем | Что говорим |
|---|---|---|---|
| 1 | 0:00 | Двойной клик по `start.bat`, сервисы поднимаются, открывается браузер | Всё запускается одной командой в Docker, локально, без систем банка |
| 2 | 0:20 | Главная → «Войти» → «Открыть демоверсию» → `client_good` | Готовые демоаккаунты под каждый сценарий, вход в один клик |
| 3 | 0:40 | Новая заявка: цель → подбор продукта → сумма и срок → данные компании подставлены → согласия → отправка | Предприниматель без банковской экспертизы выбирает продукт по задаче; данные не вводятся повторно |
| 4 | 1:40 | Экран заявки: статусы меняются вживую — проверка полноты, ЕГРЮЛ/ФНС/БКИ, скоринг, **Одобрено**, разбор решения | Банковский конвейер: проверка, обогащение данными (моки), скоринг, затем кредитная политика |
| 5 | 2:30 | «Принять» → код подписи в кабинете → **Деньги зачислены** → страница кредита, график, CSV | Подписание и выдача смоделированы внутри продукта, без SMS и почты |
| 6 | 3:00 | `client_counter`: заявка 5 млн на 12 мес. → **встречное предложение** | Решение не бинарное: банк предлагает другие условия |
| 7 | 3:30 | `client_manual` → крупная заявка → `underwriter`: очередь, разбор скоринга, эскалация → `approver`: одобрение → клиент видит результат | Нестандартные случаи решает сотрудник; роли, полномочия, аудит |
| 8 | 4:30 | `client_reject` → отказ с причиной и рекомендацией (можно кратко) | Клиент понимает, почему отказ и что делать дальше |
| 9 | 4:50 | `localhost:8000/docs` и папка `docs/` | OpenAPI, Postman, диаграмма состояний, модель данных, тесты |
