ЗАПУСК ОДНОЙ КОМАНДОЙ
  Нужен Docker Desktop (Windows / macOS) или Docker Engine 24+ с Compose v2.
  Windows:        двойной клик по start.bat
  macOS / Linux:  ./start.sh
  Вручную:        docker compose up --build

  Скрипт сам соберёт и поднимет все сервисы (PostgreSQL, API, worker, mock-gateway,
  веб-интерфейс), дождётся готовности и откроет браузер.
  Сайт и кабинеты:   http://localhost:8080
  Документация API:  http://localhost:8000/docs
  Остановка:         stop.bat  или  docker compose down

ДЕМОАККАУНТЫ (пароль у всех — demo123)
  На странице входа — кнопка «Открыть демоверсию», вход в один клик.
  client_good        кофейня: автоодобрение, подписание, выдача
  client_counter     встречное предложение банка
  client_info        запрос дополнительных документов
  client_manual      ручное рассмотрение и эскалация
  client_reject      отказ с рекомендациями
  client_young       молодой бизнес, другая лента новостей
  underwriter        специалист банка
  approver           руководитель, решения по эскалациям
  admin              правила, аналитика, имитация сбоев интеграций
